# Backend copy of demo props for Qwen Omni Vision

The agent endpoint reads `<prop_id>.jpg` from this directory when the
frontend "Show this" strip POSTs `{ image_prop_id: "<id>" }`.

Drop the same JPEGs you put in `frontend/public/demo-props/` here.
Suggested filenames (matching the frontend ShowThisStrip props list):

- cozumel-ticket.jpg
- cucina-menu.jpg
- wine-label.jpg
- allergy-card.jpg
- keycard.jpg
